    How to import into WordPress
    1. In WordPress go to Templates › Saved Templates (or Elementor › Templates).
    2. Click Import Templates, choose the downloaded .json file and click Import Now.
    3. Open any page with Elementor, click the folder icon, open My Templates and insert it.

    Needs Elementor 3.6 or newer with Flexbox Containers turned on (the default on new sites).
